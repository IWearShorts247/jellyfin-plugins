Showtime

Pre-show sequences in the spirit of CinemaVision. Clients play these before a feature when Settings → Playback → Cinema mode is on.

Drag steps by their number to reorder. Steps with nothing to play are skipped. A sequence with genres or users set takes priority over a catch-all.

    A "Home Videos" library is best (no movie metadata lookups). Lay it out like CinemaVision: Video Bumpers/<Category>, Ratings Bumpers/MPAA/PG-13.mp4, Audio Format Bumpers/Dolby Atmos, Trailers, Trivia, Music.

    Trivia reels

    Reels are rendered by the scheduled task Showtime → Render trivia reels (nightly at 4 am) into the content library. Slide packs use CinemaVision naming: Name_q.jpg, Name_c1.jpg, Name_a.jpg; any other image is a standalone slide.

    HTTP requests fired when a step starts (pick them on each step). For Home Assistant, make an automation with a Webhook trigger and use POST https://<your-ha>/api/webhook/<id>. Placeholders: {feature} {rating} {user} {step} {device}.

    See exactly what you'd get before a movie, using saved settings. Picks are random, so run it twice.
