Path Tagger

Tags every movie, series, season and episode whose file path is under a configured folder. Combine with each user's Parental Control → Block items with tags to control per-profile visibility inside shared libraries.

One mapping per line, in the form folder path|tag. Example:
D:\Media\Movies-Alex|owner-alex
D:\Media\Movies-Sam|owner-sam
The full sweep also runs as the scheduled task "Tag items by path" (daily by default; run it manually from Dashboard → Scheduled Tasks after changing mappings).
