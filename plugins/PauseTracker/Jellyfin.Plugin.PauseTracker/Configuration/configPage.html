Pause Tracker

Tracks how many times playback is paused and the length of each pause, and shows the totals in the video player overlay next to the time display.

If the web folder is not writable (some Docker setups), disable this and add the following line to index.html before </body> yourself:
<script plugin="PauseTracker" defer src="../PauseTracker/ClientScript"></script>
After returning to the menu, shows pause count, total paused time, and each pause's length. Dismisses on click/keypress or after 15 seconds.
Pauses that begin within this many minutes from the start of the media are ignored — e.g. pausing right after prerolls until everyone is ready. Set 0 to count every pause.

Track these users
